Navegação e Visualização
  • cd Muda o diretório (pasta) atual. Exemplo: cd documentos entra na pasta "documentos".
  • ls Lista os arquivos e diretórios no diretório atual. Use ls -la para ver todos os arquivos incluindo ocultos.
  • clear Limpa a tela do terminal, removendo todo o texto anterior e deixando apenas o prompt de comando.
